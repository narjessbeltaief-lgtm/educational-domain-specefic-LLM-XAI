📊 SYSTEM ARCHITECTURE
════════════════════════════════════════════════════════════════════════════

Browser (http://localhost:8080)
    ↓ Fetch API calls
    ↓
FastAPI (http://localhost:8000)
    ↓ Question Generation
    ↓

    ↓ Fresh Questions
    ↓
Response back to Browser


🔌 ENDPOINTS AVAILABLE
════════════════════════════════════════════════════════════════════════════

   → Generate fresh test with questions

POST /api/testing/answer
   → Submit and grade student answer

GET /api/testing/{test_id}/results/{student_name}
   → Get final results and score

   → Check test progress

📞 QUICK HELP
════════════════════════════════════════════════════════════════════════════

"The page won't load"
→ Restart API server (Terminal 1)
→ Hard refresh browser (Ctrl+Shift+R)

"API error when generating test"
→ Check GROQ_API_KEY is set
→ Check internet connection
→ Restart API server

"It's loading forever"
→ Check Groq API is responding (2-5 sec is normal)
→ Check browser console (F12) for errors

"UI looks weird"
→ Try different browser (Chrome recommended)
→ Clear browser cache (Ctrl+Shift+Delete)
