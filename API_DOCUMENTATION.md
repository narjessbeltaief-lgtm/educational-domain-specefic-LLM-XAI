# On-Demand Testing API

## Overview
This API allows students to take tests on-demand with questions generated fresh each time by Groq. Students receive immediate feedback and scores.

## Architecture
- **Questions generated by**: Groq LLM (via `groq` package)
- **Grading**: Simple binary scoring (10 points per correct answer)
- **Storage**: In-memory (test data persists during server session)
- **Framework**: FastAPI

## API Endpoints

### 1. Generate Test
**POST** `/api/generate`

Generate fresh questions grounded in a submitted course.

**Request:**
```json
{
  "course_name": "Introduction to Biology",
  "course_text": "This course covers cells, genetics, ecosystems, and evolution.",
  "n_questions": 20,
  "mcq_ratio": 0.5
}
```

**Response:**
```json
{
  "test_id": "abc12345",
  "course_name": "Introduction to Biology",
  "n_questions": 18,
  "questions": [
    {
      "question": "What is supervised learning?",
      "type": "mcq",
      "choices": ["...", "...", "...", "..."],
      "answer": "..."
    },
    {
      "question": "Neural networks can only solve classification problems.",
      "type": "yes_no",
      "choices": ["Yes", "No"],
      "answer": "No"
    }
  ]
}
```

### 2. Submit Answer
**POST** `/api/testing/answer`

Submit a student's answer to a question. Must include the `test_id` from the generated test.

**Request:**
```json
{
  "test_id": "abc12345",
  "student_name": "John Doe",
  "question_num": 1,
  "answer": "ResNet"
}
```

**Response:**
```json
{
  "question_num": 1,
  "correct_answer": "ResNet",
  "student_answer": "ResNet",
  "is_correct": true,
  "score": 10,
  "feedback": "Correct!"
}
```

### 3. Get Test Results
**GET** `/api/testing/{test_id}/results/{student_name}`

Get student's final test results.

**Response:**
```json
{
  "test_id": "abc12345",
  "student_name": "John Doe",
  "course_name": "Introduction to Biology",
  "total_questions": 18,
  "total_score": 160,
  "max_score": 180,
  "percentage": 88.89,
  "answers": [
    {
      "question_num": 1,
      "question": "What is supervised learning?",
      "correct_answer": "learning with labeled data",
      "student_answer": "learning with labeled data",
      "is_correct": true,
      "score": 10
    }
  ]
}
```

### 4. Check Test Status
**GET** `/api/testing/{test_id}`

Get current test progress.

**Response:**
```json
{
  "test_id": "abc12345",
  "course_name": "Introduction to Biology",
  "student_name": "John Doe",
  "total_questions": 18,
  "answered": 5,
  "remaining": 13,
  "progress": "5/18"
}
```

## Usage Examples

### JavaScript/React
```javascript
// Generate test
const testResponse = await fetch('http://localhost:8000/api/generation/', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    topic: 'machine learning',
    n_questions: 20
  })
});

const { test_id, questions } = await testResponse.json();

// Submit answer
const answerResponse = await fetch('http://localhost:8000/api/testing/answer', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    test_id: test_id,
    student_name: 'John',
    question_num: 1,
    answer: 'ResNet'
  })
});

const feedback = await answerResponse.json();

// Get results
const resultsResponse = await fetch(
  `http://localhost:8000/api/testing/${test_id}/results/John`
);
const results = await resultsResponse.json();
console.log(`Score: ${results.percentage}%`);
```

### cURL
```bash

curl -X POST http://localhost:8000/api/generation/ \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "machine learning",

curl -X POST http://localhost:8000/api/testing/answer \

  -d '{
    "test_id": "abc12345",
    "student_name": "John",
    "question_num": 1,
    "answer": "ResNet"

# Get results
curl http://localhost:8000/api/testing/abc12345/results/John
```

### Python
```python
import requests

# Generate test
response = requests.post(
    'http://localhost:8000/api/generation/',
    json={
        'topic': 'machine learning',
        'n_questions': 20
    }
)
test_data = response.json()
test_id = test_data['test_id']

# Submit answer
response = requests.post(
    'http://localhost:8000/api/testing/answer',
    json={
        'test_id': test_id,
        'student_name': 'John',
        'question_num': 1,
        'answer': 'ResNet'
    }
)
feedback = response.json()

# Get results
response = requests.get(
    f'http://localhost:8000/api/testing/{test_id}/results/John'
)
results = response.json()
print(f"Score: {results['percentage']}%")
```

## Question Types

### Multiple Choice (MCQ)
```json
{
  "question": "What model is commonly used for image classification?",
  "type": "mcq",
  "choices": ["ResNet", "LSTM", "GRU", "Attention"],
  "answer": "ResNet"
}
```

### Yes/No
```json
{
  "question": "Neural networks require labeled data.",
  "type": "yes_no",
  "choices": ["Yes", "No"],
  "answer": "Yes"
}
```

## Scoring

- **Per question**: 10 points (correct) or 0 points (incorrect)
- **Total**: Sum of all question scores
- **Percentage**: (Total Score / Max Score) × 100
